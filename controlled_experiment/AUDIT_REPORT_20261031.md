# GraphReaction 本机数据与训练流程审计

日期：2026-10-31。范围：原全量训练历史138、141、154、155及独立的有限检查。

## 结论与边界

本轮没有发现原全量实验的损失定义、标签时间对齐、训练统计来源、累计梯度尾组或best选择存在可复现的计算错误。因此没有修改原模型、原损失、默认训练流程或数值协议。当前根目录运行源码与155断点保存的源码哈希一致。

原训练仍暂停于155，正式best仍为154，依据在线训练原CE2选择。所有旧best/last、历史评价、数据划分和归一化文件保留。没有云端连接、上传、正式训练或新增测试集动态评价。

确认的限制和风险：

1. CUDA重复前向存在小幅差异，部分节点超过原对拍容差；CPU对照一致。它与原协议未强制确定性计算相容，但未定位到具体算子，不写成已证明的单一原因。没有调宽容差或修改默认计算协议。
2. 原始仿真目录在本机不可用，93份来源SHA256均为空。处理后训练/验证内容没有完全重复，不能据此证明底层随机来源独立，也不能排除近重复。
3. 原实验只剩4个固定权重点；未保存轮次不能补造固定评价。没有142开始时的独立快照，无法仅靠当前文件逐位复演141→142边界。
4. 新A/B工具的测试发现CPU优化器加载可能复用输入张量，已在新 `initialize_branch` 中深复制优化器状态，并验证两组storage独立、父payload不变。此问题不是对原历史训练的错误指控。

## 损失、汇总与训练实现

令各L为单窗口标准化增量MSE，则：

```
CE2 = (2*L_ce + L_cg + L_cp + L_phi_e + L_phi_p + L_phi_CBD + L_V)/8 + 0.1*L_I
Q_ref = (L_ce + L_cg + L_cp + L_phi_e + L_phi_p + L_phi_CBD + L_V)/7 + 0.1*L_I
C_mean = (2*L_ce + L_cg + L_cp)/4
P_mean = (L_phi_e + L_phi_p + L_phi_CBD)/3
CE2 = 0.5*C_mean + 0.375*P_mean + 0.125*L_V + 0.1*L_I
L_I = ((I_pred - I_app)/abs(I_app))^2
```

ce和phi_e先在phase2/5各自节点内求MSE，再按0.5/0.5平均；V单列，不重复加入P。电流只加入一次，其反向依赖保留，日志detach不影响优化loss。`training_step.train_group`反向使用 `losses['loss']/实际组窗口数`，即原CE2；`main_loss`为分母8的物理场部分，total/CE2再加0.1电流。

`Q_ref`是当前七字段等权物理损失加0.1电流；不能将它混同此前截图中另含独立集流体辅助项、字段集合不同的其他“论文总损失”。本轮没有重定义Q_ref。

每轮在线指标是参数不断更新时的逐窗口值之算术平均，不再次除4。固定checkpoint评价独立记录，不能将在线指标当作该固定模型在训练集的误差。65/14轨迹的总评价按窗口平均，轨迹均值合并时按各自窗口数加权，而不是对轨迹等权。已有8组评价窗口集合完全匹配；从逐轨迹重建总体、重建CE2/Q_ref和区域等权的最大误差低于1e-12，实测值见coverage文件。

物理场 `standardized_node_pooled_MSE` 另行累加所有有效节点SSE/count；ce/phi_e在此包含两个区域所有有效节点，不套用0.5/0.5。NRMSE_delta最后只开一次平方。字段、时间箱、区域报告中此节点口径不能冒充训练的区域等权损失。

全888,460条更新日志核验：每组zero_grad一次→各窗口backward→组末clip一次→step一次。22,927窗口每轮5,732更新，末3窗除3且有step，下一组清零。没有遗留到下一轮、漏step或日志二次除4。原代码无AMP、无TF32，梯度裁剪阈值1。

## 154→155：已确认事实与解释限度

复用完整固定评价，未重跑四组历史模型：电势组训练下降24.21%、验证下降36.93%；训练浓度组上升2.71%，验证浓度近似不变。155是四个已保存点中验证CE2最低，仍不替代正式best154。

- 电势改善51/65训练轨迹、10/14验证轨迹。训练主要贡献来自r081/r018/r061；验证来自r021/r057/r092。前三条占各自“改善轨迹的改善量总和”21.95%/51.91%，不是净改善占比。改善并非只发生在一条轨迹，但验证贡献仍有集中性。
- 以已有节点合并MSE看：训练phi_e/phi_p/phi_CBD分别在6/8、6/8、7/8时间箱改善；验证为5/8、7/8、8/8。验证phi_e早期bin0、bin1反而增加64.41%、34.34%，bin7下降67.07%。这些箱是每轨迹等数量时间箱，不是统一SOC或绝对时间段。
- 验证phi_e在NEG/SEP/POS节点合并MSE分别下降41.03%/51.17%/35.25%；phi_p/CBD在POS下降33.92%/32.01%。不能解释为只有某一区域修复。
- 验证端电压有符号均值从−0.007113mV变为−0.004661mV，误差标准差从0.016187mV降至0.013778mV；训练也同时减小偏移与分散。说明端电压恢复包含共同偏移和分散两方面，不能只归因于一个常数偏置。
- 原逐节点有符号电势误差未全部保存。本轮没有新做完整节点预测，因此不能把端电压偏移结论推广为所有空间电势场的共同偏移。

证据支持“相邻固定权重间存在任务和样本依赖的波动”。只有四点，不支持持续退化定性；不能确认过拟合、任务冲突、采样顺序或AdamW瞬时状态中的哪一项造成变化。

## 重复评价与有限运行结果

18固定窗口（train/validation各3轨迹×首/中/末）各评价5次。CUDA最大节点预测差1.52588e-5，部分超出既有容差atol2e-6/rtol2e-5；CE2最大绝对差2.38896e-8，最大相对差0.001520%，CE2全部满足原loss容差atol1e-9/rtol2e-4。CPU抽取3窗各5次，预测和CE2差均为0。两者均未更新参数/缓冲区。

抽样损失波动远小于154→155电势组数十个百分点变化，但这不是对整套训练所有数值路径的严格上界。没有为让测试通过而放宽容差，也没有将CUDA节点重复检查写成通过。
